# تدريب أوزان Labras AI (LoRA)

هذا المسار ينفذ تدريباً فعلياً قابلاً للتحقق، وليس مجرد استدعاء نموذج عبر API.

## ما الذي سينتج؟
- النموذج الأساسي المقترح: `Qwen/Qwen2.5-0.5B-Instruct` (نموذج مفتوح صغير كبداية).
- ملف LoRA adapter محفوظ في `training/output/labras-lora`.
- هذه الأوزان المتعلّمة تخص ضبط Labras، لكنها ليست نموذج 1B مدرّباً من الصفر ولا تستبدل أوزان النموذج الأساسي.

## التشغيل على جلسة GPU مجانية إن توفرت
1. افتح Google Colab أو Kaggle Notebook من الهاتف أو الكمبيوتر، واختر GPU إذا كان متاحاً في حسابك.
2. ارفع نسخة المستودع أو استنسخه داخل الجلسة.
3. نفّذ:
   `pip install -r training/requirements.txt`
4. نفّذ:
   `python training/train_lora.py --data_dir data --output_dir training/output/labras-lora`
5. لا تعتبر التدريب ناجحاً إلا إذا ظهر ملف `adapter_config.json` وملفات `adapter_model.safetensors` في مجلد الإخراج.

## حدود المجانية
توفّر GPU المجاني يتغير حسب المنصة والحساب والضغط، ولا يمكن ضمانه أو إبقاء الجلسة تعمل بلا انقطاع. لا تدخل بيانات دفع ولا تفعّل خطة مدفوعة دون موافقتك.

## تنبيه جودة
ملفات البيانات الحالية تحتوي أمثلة اصطناعية تحمل `needs_human_review`. السكربت يستبعد أي سجل لا يحمل رسالة مستخدم ومساعد صالحتين، لكنه لا يجعل الإجابات صحيحة تلقائياً. راجع البيانات قبل تدريب إنتاجي.

## الدمج في التطبيق
هذا التدريب ينتج LoRA adapter. تشغيله يتطلب بيئة تدعم Transformers وPEFT؛ Cloudflare Worker الحالي لا يستطيع تحميل هذه الملفات مباشرة. لا تغيّرنا مسار Worker إلى ادعاء أن الأوزان مستخدمة قبل نشر inference runtime يدعمها.
